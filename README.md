# Terminal Notes

Консольное приложение для создания и просмотра заметок. Проект написан на C++ и предназначен для работы в Linux-терминале.

## Текущая версия

**v0.1 — Basic Notes**

В этой версии реализованы базовые операции с заметками:

- Создание заметки.
- Просмотр списка заметок.
- Открытие заметки по индексу.
- Поддержка пустого заголовка и пустого содержимого.
- Заголовок по умолчанию — `Новый заголовок`.
- Ограничение хранилища — 100 заметок.
- Обработка некорректного пользовательского ввода и EOF.

Заметки хранятся только в оперативной памяти. После завершения программы они не сохраняются.

## Технологии

- C++20
- GCC / G++
- GDB
- Visual Studio Code

## Сборка и запуск

Перейдите в корневую директорию проекта и выполните:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic main.cpp -o terminal-notes
./terminal-notes
```

## Запуск и отладка в Visual Studio Code

В проекте подготовлены конфигурации:

- `.vscode/tasks.json` — сборка приложения.
- `.vscode/launch.json` — запуск и отладка через GDB.

Для запуска откройте корневую папку проекта в VS Code и нажмите **F5**.

Необходимы компилятор G++, отладчик GDB и расширение **C/C++** от Microsoft.
