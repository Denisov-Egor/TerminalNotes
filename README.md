# Terminal Notes

Консольное приложение для создания, просмотра и хранения заметок. Проект написан на C++ и предназначен для работы в Linux-терминале.

## Текущая версия

**v0.2 — Persistent Storage**

В этой версии реализовано базовое управление заметками и файловое хранение.

### Возможности

- Создание заметок.
- Просмотр списка заметок.
- Открытие заметки по индексу.
- Поддержка пустого заголовка и пустого содержимого.
- Поддержка многострочного содержимого.
- Заголовок по умолчанию — `Новый заголовок`.
- Ограничение хранилища — 100 заметок.
- Сохранение заметок в текстовый файл `notes.txt`.
- Загрузка заметок из `notes.txt` через меню приложения.
- Проверка корректности формата файла.
- Защита от загрузки более 100 заметок.
- Сохранение текущих заметок в памяти при ошибке загрузки.
- Обработка некорректного пользовательского ввода и EOF.

Заметки хранятся в оперативной памяти во время работы приложения. Для сохранения между запусками необходимо использовать пункт сохранения в меню, а после запуска — пункт загрузки.

## Технологии

- C++20
- GCC / G++
- GDB
- Visual Studio Code

## Сборка и запуск

Перейдите в корневую директорию проекта и выполните:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic main.cpp -o terminal-notes
./terminal-notes
```

## Запуск и отладка в Visual Studio Code

В проекте подготовлены конфигурации:

- `.vscode/tasks.json` — сборка приложения.
- `.vscode/launch.json` — запуск и отладка через GDB.

Для запуска откройте корневую папку проекта в VS Code и нажмите **F5**.

Необходимы компилятор G++, отладчик GDB и расширение **C/C++** от Microsoft.

## Структура проекта

```text
TerminalNotes/
├── .vscode/
│   ├── launch.json
│   └── tasks.json
├── main.cpp
├── notes.txt
└── README.md
```

На текущем этапе исходный код находится в одном файле. Файл `notes.txt` создаётся при первом сохранении заметок.

## Планы развития

- **v0.1 — Basic Notes:** создание, просмотр и открытие заметок.
- **v0.2 — Persistent Storage:** сохранение и загрузка заметок из файла.
- **v0.3 — Note Management:** редактирование заголовка и содержимого, удаление заметок и подтверждение удаления.
- **v0.4 — Search & Navigation:** поиск заметок и навигация по результатам.
- **v0.5 — Import & Export:** импорт и экспорт заметок.
- **v0.6 — Organization:** категории, теги, фильтрация и сортировка.
- **v0.7 — Application Configuration:** настройки приложения.
- **v1.0 — Stable Release:** стабилизация, тестирование, разделение исходников, CMake и документация.

Функциональность будет добавляться постепенно. Приоритет — понятная архитектура, надёжность и решение конкретных задач без избыточных возможностей.
